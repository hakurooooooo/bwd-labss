О приложении

TaskMaster — это веб-приложение для управления задачами, созданное в рамках лабораторных работ по курсу «Основы веб-разработки».

В проекте реализованы:

  • Адаптивная вёрстка (десктоп / планшет / телефон)
  • Flexbox-раскладка карточек задач
  • Бургер-меню с анимацией
  • Модальное окно на основе тега <dialog>
  • Интерактивное управление задачами через JavaScript
  • Сохранение задач в localStorage
  • Автоматическое перемещение задач между колонками
  • Сортировка задач по алфавиту (А→Я / Я→А)
  • Модульная архитектура кода
